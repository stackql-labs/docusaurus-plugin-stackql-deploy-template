# Changelog

## 0.1.0

First release. The stackql-deploy template menu moves out of the provider sites (`src/components/StackqlDeployDropdown` and the `src/theme/DocBreadcrumbs` swizzle, identical in all of them) into this plugin, which now owns how the template is built, where the menu is placed and when it is shown.

### Changed (compared with the site component)

- **Placement.** The menu and the Ask AI button of `@stackql/docusaurus-plugin-aeo` sit together at the right of the breadcrumb row. With the site swizzle, the AEO row (breadcrumbs and Ask AI) was nested in a second row, so the Ask AI button followed the breadcrumbs instead of sitting at the right edge, and on resource pages it was separated from the menu.
- **Templates of pages generated by `@stackql/provider-utils`.** These pages mark required parameters with `-- required` comments and have no anchors in their examples. The site component built invalid templates from them:
  - the `exists`, `statecheck` and `exports` conditions were joined with ` AND` after the comment, so the comment swallowed the `AND`;
  - the optional parameters (`expand`, `start_at`, `max_results`) became conditions;
  - the INSERT, UPDATE and DELETE examples had no `/*+ create */`, `/*+ update */` and `/*+ delete */` anchors.
  
  The generated queries now keep the required conditions only, without the comments, and the examples get their anchor unless they start with one. The statecheck compares each column with the value the INSERT example gives it (strings quoted), instead of an unquoted `{{ column }}`.
- **Preferred tabs.** The SELECT example is the `get` tab wherever it is in the section (the component found the `get (all properties)` tab or fell back to the first tab, which on most generated pages is `list`), and the INSERT example the `All Properties` or `create` tab. Without a DELETE section, only a `delete` lifecycle tab supplies the delete (the component took the first lifecycle method otherwise).
- Templates of the `awscc` pages are unchanged: the same output for all 1,237 resource pages.
- The button has the AEO button's styling (hover tint of the site's primary colour, `aria-haspopup` and `aria-expanded`), and its strings go through `translate()`.

### Added

- Options: `placement`, `askAi`, `showOnMobile`, `resourceRoute`.
- A build error when the plugin is listed before `@stackql/docusaurus-plugin-aeo`, whose `DocBreadcrumbs` would otherwise replace this plugin's row without a message.
- `@stackql/docusaurus-plugin-stackql-deploy-template/template`: the template logic as a CommonJS module.
- Tests (`npm test`) and a CI workflow.
